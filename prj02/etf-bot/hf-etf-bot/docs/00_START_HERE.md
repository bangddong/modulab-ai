## 주요 기능

### 1. 투자 프로필 자동 분석
```
입력: "30대 직장인, 월 100만원, IT 선호, 보수적"
출력: 구조화된 투자 프로필 (위험성향, 기간, 금액 등)
```

### 2. Text2SQL + RAG
```
프로필 → Few-shot 예제 참조 → SQL 생성 → 검증 → 실행
실패 시 → 재시도 (최대 3회) → Fallback 쿼리
```

### 3. 종합 평가 및 순위
```
수익성 + 안정성 + 비용 + 적합성
→ 성향별 가중치 적용
→ Top 3 선정
```

### 4. 포트폴리오 다양성 분석
```
섹터 분산 + 위험 분산 + 자산 다양성
→ 종합 점수 (0-100)
→ 개선 제안
```

### 5. 상세한 투자 가이드
```
전략 개요 + ETF 상세 (3개) + 투자 비중 + 위험 요소 + 고려사항
→ 마크다운 형식으로 출력
```
