## 시작하기

### 접속 방법

1. 웹 브라우저에서 앱 URL 접속
2. 채팅 인터페이스 확인
3. 텍스트 입력창에 질문 작성
4. Enter 또는 "Submit" 버튼 클릭

### 첫 질문 작성

시스템이 최적의 추천을 제공하려면 다음 정보가 필요합니다:

```
필수 정보:
1. 투자 목적
2. 투자 기간
3. 위험 성향
4. 월 투자 금액

선택 정보:
5. 선호 섹터
6. 제외 섹터
7. ESG 선호도
```

## 효과적인 질문 작성법

### 좋은 질문의 예

#### 예제 1: 보수적 투자자

```
저는 40대 중반 직장인입니다. 노후 대비를 위해 월 200만원씩 15년 이상
장기 투자할 계획입니다. 안정적인 배당 수익을 원하며, 원금 손실 위험을
최소화하고 싶습니다. 국내외 시장에 분산 투자하고 싶고, 담배나 무기
관련 기업은 제외해주세요.
```

**분석**:
- 투자 목적: 노후 대비
- 투자 기간: 15년 (장기)
- 위험 성향: 보수적
- 월 투자액: 200만원
- 선호: 배당, 분산 투자
- 제외: 담배, 무기

#### 예제 2: 공격적 투자자

```
20대 후반 직장인입니다. 월 150만원을 2년 정도 투자하려고 합니다.
높은 수익을 기대하며 단기 변동성은 감수할 수 있습니다.
미국 IT 섹터와 바이오/헬스케어에 관심이 많고, ESG 투자도
고려하고 싶습니다.
```

**분석**:
- 투자 목적: 자산 증식
- 투자 기간: 2년 (중기)
- 위험 성향: 공격적
- 월 투자액: 150만원
- 선호: 미국 IT, 바이오/헬스케어, ESG

#### 예제 3: 중도적 투자자

```
30대 초반입니다. 결혼 자금 마련을 위해 월 100만원씩 3년간
투자하고 싶습니다. 적당한 수익을 기대하지만 너무 위험하지 않았으면
좋겠습니다. 국내 대형주와 해외 주요 지수 ETF에 관심이 있습니다.
```

**분석**:
- 투자 목적: 결혼 자금
- 투자 기간: 3년 (중기)
- 위험 성향: 중도적
- 월 투자액: 100만원
- 선호: 국내 대형주, 해외 지수

## 추천 결과 해석

### 결과 구조

추천 결과는 다음과 같이 구성됩니다:

```
1. 투자 전략 개요
   └─ 전체 포트폴리오 방향성

2. 추천 ETF 포트폴리오 테이블
   └─ ETF명, 종목코드, 추천비중

3. ETF 상세 분석 (3개)
   ├─ ETF 설명
   ├─ 주요 투자 포인트
   └─ 투자 위험 요소

4. 투자 시 고려사항
   └─ 실행 가이드 및 주의사항
```

### 추천 비중 이해하기

#### Conservative (보수적)

```
1위: 50% - 가장 안정적인 ETF
2위: 30% - 중간 안정성
3위: 20% - 추가 분산용
```

**특징**: 안정성 중심 배분

#### Moderate (중도적)

```
1위: 40% - 균형잡힌 배분
2위: 35%
3위: 25%
```

**특징**: 균형잡힌 배분

#### Aggressive (공격적)

```
1위: 45% - 고수익 집중
2위: 30%
3위: 25%
```

**특징**: 상위 종목 집중

### 주요 투자 포인트

각 ETF마다 3-4개의 핵심 포인트 제공:

- 수익성 측면
- 안정성 측면
- 비용 효율성
- 프로필 적합성

### 위험 요소

각 ETF의 2-3가지 리스크 요인:

- 시장 위험
- 특정 섹터 위험
- 환율 위험 등

## 실전 예제

### 시나리오 1: 퇴직 준비

**상황**:
- 50대 초반
- 10년 후 퇴직 예정
- 퇴직금 일부 운용 계획
- 월 300만원 투자 가능

**질문 작성**:

```
50대 초반 직장인입니다. 10년 후 퇴직을 대비하여 월 300만원씩
투자하고 싶습니다. 안정적인 수익을 원하며, 퇴직 후 연금처럼
정기적인 수익이 나왔으면 좋겠습니다. 변동성이 큰 투자는 피하고
싶고, 채권이나 배당주 중심으로 구성하고 싶습니다.
```

**예상 추천**:
- 채권형 ETF
- 배당주 ETF
- 안정적 대형주 ETF

### 시나리오 2: 자녀 교육비

**상황**:
- 30대 중반 부부
- 자녀 5세
- 대학 입학 시 사용할 자금
- 월 50만원 투자

**질문 작성**:

```
30대 중반 부부입니다. 5세 자녀의 대학 교육비 마련을 위해
월 50만원씩 13년간 투자하려고 합니다. 중간 정도 위험은 감수할 수
있지만, 교육비라는 명확한 목표가 있어 큰 손실은 피하고 싶습니다.
국내외 균형잡힌 포트폴리오를 원합니다.
```

**예상 추천**:
- 글로벌 지수 ETF
- 국내 대형주 ETF
- 혼합형 ETF

### 시나리오 3: 단기 목돈 마련

**상황**:
- 20대 후반
- 1-2년 내 결혼 예정
- 빠른 자산 증식 희망
- 월 100만원 투자

**질문 작성**:

```
20대 후반이고 2년 내 결혼을 앞두고 있습니다. 월 100만원을
투자하여 빠르게 자산을 늘리고 싶습니다. 단기 변동성은 감수할 수
있으며, 성장 가능성이 높은 섹터에 투자하고 싶습니다.
IT, 전기차, 바이오 등 성장 산업에 관심이 있습니다.
```

**예상 추천**:
- IT 섹터 ETF
- 성장주 ETF
- 테마형 ETF

## FAQ

### Q1. 추천 결과가 나오는 데 시간이 얼마나 걸리나요?

**A**: 일반적으로 10-20초 소요됩니다. 다음 단계를 거칩니다:

1. 프로필 분석 (2초)
2. SQL 쿼리 생성 (3초)
3. 데이터베이스 검색 (1초)
4. ETF 평가 및 순위 (3초)
5. 다양성 분석 (2초)
6. 추천 설명 작성 (3-5초)

### Q2. 같은 질문을 다시 하면 같은 결과가 나오나요?

**A**: 거의 유사하지만 완전히 동일하지는 않습니다. LLM의 특성상 약간의 변동이 있을 수 있습니다.

### Q3. 추천 비중을 그대로 따라야 하나요?

**A**: 아니요. 추천 비중은 참고사항입니다. 개인 상황과 판단에 따라 조정하세요.

### Q4. 월 투자 금액을 정확히 입력해야 하나요?

**A**: 대략적인 금액으로도 충분합니다. 시스템은 투자 규모를 참고하여 ETF를 선정합니다.

### Q5. ETF를 실제로 어떻게 매수하나요?

**A**: 본 시스템은 추천만 제공합니다. 실제 매수는:

1. 증권사 계좌 개설
2. 추천받은 ETF 종목코드 검색
3. 원하는 수량 매수
4. 정기적으로 포트폴리오 점검

### Q6. 추천 결과가 마음에 안 들면?

**A**: 질문을 수정하여 다시 시도하세요:

- 더 구체적인 선호 사항 추가
- 제외 조건 명시
- 위험 성향 재조정

### Q7. 여러 개 추천받고 비교할 수 있나요?

**A**: 네. 다양한 시나리오로 여러 번 질문하여 비교해보세요:

```
시나리오 1: 보수적 투자
시나리오 2: 공격적 투자
시나리오 3: ESG 중심
```

### Q8. 추천받은 ETF를 모두 매수해야 하나요?

**A**: 아니요. 상황에 맞게 선택하세요:

- 1-2개만 선택 가능
- 비중 조정 가능
- 일부만 우선 매수 후 추가 가능

### Q9. 얼마나 자주 리밸런싱해야 하나요?

**A**: 일반적으로:

- 보수적 포트폴리오: 연 1-2회
- 중도적 포트폴리오: 분기별
- 공격적 포트폴리오: 월별 점검

### Q10. AI 추천을 얼마나 신뢰할 수 있나요?

**A**: 본 시스템은 보조 도구입니다:

**장점**:
- 데이터 기반 객관적 분석
- 다양한 요소 종합 평가
- 빠른 정보 처리

**한계**:
- 실시간 시장 상황 미반영
- 과거 데이터 기반
- 개인 특수 상황 고려 제한

**권장 사항**:
1. AI 추천을 참고 자료로 활용
2. 추가로 ETF 상세 정보 조사
3. 필요 시 전문가 상담
4. 최종 결정은 본인이 수행
