# 변경 이력

## v2.0.0 (2025-01-18)

### 주요 개선 사항

#### 1. Text2SQL 성능 향상

**추가**
- Few-shot learning 예제 3개 추가
- SQL 쿼리 검증 메커니즘 구현
- 재시도 로직 (최대 3회)
- Fallback 쿼리 시스템

**개선**
- 쿼리 생성 프롬프트 상세화
- 위험 성향별 쿼리 최적화
- 한국어 고유명사 매칭 정확도 향상

#### 2. 평가 시스템 고도화

**추가**
- 투자 성향별 가중치 차별화
  - Conservative: 안정성 40%, 비용 30%, 수익성 20%, 적합성 10%
  - Moderate: 각 25%
  - Aggressive: 수익성 50%, 적합성 30%, 안정성 10%, 비용 10%
- 포트폴리오 다양성 분석 노드
  - 섹터 분산 평가
  - 위험 분산 평가
  - 다양성 점수 (0-100)

**개선**
- 랭킹 프롬프트 구체화 (최소 3-4문장)
- ETF 평가 기준 명확화

#### 3. 사용자 경험 개선

**추가**
- ESG 투자 선호도 옵션
- 투자 비중 자동 계산
  - Conservative: 1위 50%, 2위 30%, 3위 20%
  - Moderate: 1위 40%, 2위 35%, 3위 25%
  - Aggressive: 1위 45%, 2위 30%, 3위 25%
- 상세한 오류 메시지
- 입력 검증 (최소 10자)

**개선**
- Gradio 인터페이스 설명 확장
- 예제 쿼리 4개로 증가
- 마크다운 출력 포맷 개선

#### 4. 프롬프트 엔지니어링

**개선**
